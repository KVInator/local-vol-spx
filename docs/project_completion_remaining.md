# Remaining work and defensible completion conditions

Steps 1 and 2 have saved evidence: October result audit and surface consolidation. The independent total-variance interpolator's failures are documented, rather than hidden or promoted as an arbitrage-free diffusion. The raw data audit covers 2013–2023; daily calibration and hedge results currently cover the inspected September/October development samples.

| Step | Remaining work | Completion condition |
| --- | --- | --- |

Optimal hedging | Run the new stage on the pinned September/October panels and interpret slope/support failures, empirical coefficients, coverage and matched Gain. | Distinct HW LV smile approximation, declared sticky conventions, ordinary AH PDE delta and past-only empirical correction have tested implementations and measured results. |

Known-model theory | Add a common-path known-model hedge experiment, several rebalancing frequencies, analytical controls and measured sampling/numerical uncertainty. | Expected continuous-hedge replication and discrete error behaviour are supported within measured error; no attempt to force historical outcomes to match the model. |

Any prior inspected period is labelled development. |
| 6. Complete interface | Extend the existing saved-results notebooks into one indexed master notebook covering the whole evaluated history and all implemented evidence. | Date selection, surface views, validation, strategies, failures and historical summaries use the same verified run index. |
| 7. Final package | Technical report, substantive README, assumptions register, environment specification, representative outputs, final tests and release. | Every CQF/academic/resume claim maps to actual code and measured results; GitHub content excludes licensed raw data and large generated runs. |

“All data” means a sequence of **same-date calibrated surfaces**, not one surface calibrated by pooling future and past dates. Hedging evaluation remains chronological. More dates do not fix missing contract identity, snapshot provenance, historical fixing or funding evidence; those limitations stay in the final report.

Finishing requires executing and reviewing these remaining experiments. A deadline does not justify calling the full historical study complete before it has run. The timing already recorded for October can guide a workload estimate, but it does not establish the runtime of every historical period.
